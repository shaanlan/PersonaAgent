# 目标：在mbti评测独立网站上增加一个智能对话新功能
# 要求：
1、当前项目提供后端服务，实现api，相应前端的对话请求，查询各类数据，调用llm生成回复信息
2、要基于agent workflow的设计来实现：
- 目的是熟悉ai agent设计开发流程，要包含agent开发核心部分和功能。先力求完成基本的核心功能，保持精简。
- 生成代码能够用于阅读学习agent设计开发。
- 能够在应聘面试流程中证明作者本人具有agent设计开发能力。
3、当前网站已经建设了一批基本功能：用户自测mbti类型、用户测试别人的mbti类型、用户进行双人对比测试分析；也完成了一批内容专栏：职业探索、关系探索、关系故事系列；还包含基本的16种mbti类型的详情页，以及网站基本介绍页面等等。都可以用于回复用户对话问题：
- xxx是什么类型？我真的是xxx类型么？ => 跳转到自测页面或者第三人测试页面
- 我是xxx，适合和什么类型谈恋爱？ => 跳转到关系探索页面
- 我的mbti和他的mbti配么？ => 跳转到双人测试分析，或者关系探索页面
- 怎么判断一个人的 MBTI？怎么测我女朋友的 MBTI？=> 跳转到第三人测试页面
- 他是 INTJ，为什么总是不主动表达感情？=> 跳转到mbti类型详情页
- INFP 适合做什么职业？=> 跳转到职业探索页面
- 哪些 MBTI 类型最适合做朋友？=> 跳转到关系探索页面
- MBTI 的四个字母是怎么测出来的？ => 跳转到博客页面
# 技术要求：
1、技术栈：python、fastapi，langgraph，先基于ollama本地提供服务，也可配置远程，rag存储线优先轻量级（也得是用的比较多的技术）；有人建议LiteLLM，你看看如果合适就用，或者给出更合适的选型
2、适配当前前端方案 vue3 + nuxt3，阿里云结点部署，当前结点部署了mysql

- 内容生产端: ./ref/content/requirement.md, ./ref/content/design.md
- 补充账户系统相关文档: ./ref/user_account/
